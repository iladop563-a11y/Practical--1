# Практична робота №1

Дисципліна: Програмування

Тема: Розробка програмних модулів з використанням базових операторів, умовних конструкцій та циклів.

Виконав: Кузін Ілля

## Мета роботи

Опанування базових операторів, умовних конструкцій та циклів у Python.

## Завдання

1. task 1 — Обчислення математичних виразів.
2. task 2 — Конвертор типів.
3. task 3 — Класифікація оцінок.
4. task 4 — Визначення типу трикутника.
5. task 5 — Обчислення факторіалу та таблиці множення.
6. task 6 — Інтерактивний калькулятор.

## Вимоги

Python 3.10 або новіший.

Додаткові бібліотеки не потрібні.

## Інструкція запуску

1. Завантажити репозиторій.
2. Встановити Python.
3. Відкрити термінал у папці проєкту.
4. Виконати команду:

```bash
python "task 1"
```

Для запуску інших програм замінити номер завдання.

## Висновок

У практичній роботі реалізовано шість програм мовою Python із використанням арифметичних операторів, умовних конструкцій, циклів та обробки помилок.
